# Yamone English

한국어 사용자를 위한 음성 중심 영어 회화 학습 앱입니다.

## v0.8.1 범위

### 과정
- 영어권 5~7세 과정: 100개 레슨
- 영어권 8~10세 과정: 100개 레슨
- 영어권 11~13세 과정: 100개 레슨
- 영어권 14~16세 과정: 100개 레슨
- 영어권 17~20세 과정: 100개 레슨
- 총 500개 레슨
- 홈에서 과정 선택
- 과정별 학습·듣기·어순·복습 데이터를 분리
- 화면 번호는 각 과정에서 1번부터 시작

### 과정 종료 테스트
- 5~7세: 16문항
- 8~10세: 20문항
- 11~13세: 24문항
- 14~16세: 28문항
- 17~20세: 28문항
- 듣기·말하기·영어식 어순·상황 대응/판단을 확인
- 틀린 종료 테스트 문항은 통합 자동 복습에 반영
- 과정별 평가 결과 저장소 이름과 저장 키는 기존 버전과 동일하게 유지

### 학습
- 레슨별 자연스러운 실제 회화 핵심 표현
- 모든 500개 레슨에 정확히 6턴 대화
- 영어식 사고·어순 가이드
- 미국식 실제 회화 기준 발음·연결·강세·억양 가이드
- 듣기 → 이해 → 말하기 → 내 표현 → 대화 흐름
- 틀린 듣기·말하기·어순 항목을 통합 자동 복습

### v0.8.1 출시 전 통합 안정화 2차
- 홈의 과정 진행 상태를 `CourseProgressResolver` 기준으로 통일
- 100/100 전에는 정확한 다음 미완료 레슨과 남은 레슨 수를 표시
- 100/100 완료 뒤 마지막 레슨을 `이어서 학습`으로 다시 노출하지 않고 과정 완료 및 종료 테스트 진입을 우선 표시
- 과정 테스트 카드에서 레슨 진행 중/100개 완료/기존 결과 보유 상태를 구분해 안내
- 선택 과정 외 완료·어순·복습 데이터가 홈 카운트와 복습 화면에 섞이지 않도록 필터 강화
- 저장된 레슨 ID 중 삭제되었거나 잘못된 ID는 읽을 때 안전하게 무시
- 레슨 데이터·섹션이 비정상적으로 비어 있어도 홈에서 크래시하지 않는 빈 상태 처리 추가
- 레슨 예문 목록이 비어 있어도 `first()` 호출로 종료되지 않도록 방어
- 모든 TTS 호출을 공통 경로로 통합하고 TTS 준비 실패/영어 음성 미지원 시 Snackbar 안내 추가
- 기존 SharedPreferences 이름·키·평가 저장소 이름은 그대로 유지
- 설정 화면 버전을 v0.8.1로 갱신

### v0.8.0 출시 전 통합 안정화 1차
- 기존 SharedPreferences 이름과 평가 저장 키를 `PersistenceContract`로 고정해 재설치가 아닌 일반 업데이트 시 기존 기록 호환성을 보호
- 5개 과정의 완료 레슨을 서로 섞지 않는 `CourseProgressResolver` 추가
- 과정별 100개 레슨 완료/미완료/다음 레슨 계산 회귀 테스트 추가
- 5개 과정 평가 진입 데이터와 레슨 소속 검증 추가
- 듣기 훈련의 의미 선택지를 현재 선택 과정 안에서만 만들도록 수정
- 듣기 레슨 선택 번호가 내부 ID가 아니라 과정 번호 1~100으로 표시되도록 수정
- 듣기 화면에 과정 데이터 누락 시 안전한 빈 상태 처리 추가
- 음성 인식 중복 시작·취소·빈 결과·서비스 오류 처리 강화
- 자동 복습 저장소가 존재하지 않는 레슨 ID를 기록하지 않도록 방어 로직 추가

### 품질 점검
- 5개 과정 × 100개 레슨의 고정 ID와 과정별 1~100 번호 검사
- 모든 레슨의 6턴 대화 존재 여부 및 빈 문장 검사
- 영어식 어순 가이드와 발음·연결·강세·억양 가이드 누락 검사
- 과정별 섹션이 각 레슨을 정확히 한 번 포함하는지 검사
- 14~16세·17~20세 종료 테스트 문항 수·분야 균형·전 범위 샘플링 검사
- 저장소/저장 키 이름이 과거 버전과 동일한지 회귀 검사
- 99/100과 100/100 홈 흐름을 5개 과정 모두 회귀 검사
- 잘못된 저장 레슨 ID와 타 과정 ID를 안전하게 무시하는지 검사
- 선택 과정 이외의 레슨이 진행률에 섞이지 않는지 회귀 검사

### 공통
- Android 기본 TTS(TextToSpeech) 영어 듣기
- 천천히 / 학습 / 자연 / 실제 빠름
- 영어만 / 영어→해석 / 영어→해석→영어 연속 듣기
- Android SpeechRecognizer 말하기 인식
- 한국어 음성 → 자연스러운 영어 표현 추천
- 로그인/광고/콘텐츠 업데이트/온라인 AI는 구조만 준비하고 비활성

## 실행
1. Android Studio에서 저장소를 엽니다.
2. JDK 17을 사용합니다.
3. Gradle Sync 후 Android 기기에서 실행합니다.
4. 첫 음성 입력 때 마이크 권한을 허용합니다.

CI에서는 `:app:testDebugUnitTest`로 카탈로그·과정 분리·저장 키·홈 완료 흐름 회귀 테스트를 실행한 뒤 `:app:assembleDebug`로 APK를 빌드합니다.

> 음성 인식은 기기에 설치된 Android 음성 인식 서비스 상태에 따라 네트워크가 필요할 수 있습니다.
