# Yamone English

한국어 사용자를 위한 음성 중심 영어 회화 학습 앱의 첫 실행 버전입니다.

## v0.1.1 범위
- 영어권 5~7세 수준의 일상 표현 24개를 앱 내부에 포함
- 듣기 → 의미 이해 → 따라 말하기 → 내 표현 → 짧은 대화 → 완료 흐름
- Android 기본 TTS(TextToSpeech)로 영어 듣기
- 영문/한글 발음 가이드와 강세·연결·억양 표시
- Android SpeechRecognizer로 영어 말하기 인식
- 완료/복습 기록을 기기 로컬에 저장
- 자유 말하기용 로컬 대화 코치
- 로그인/광고/콘텐츠 업데이트/온라인 AI는 구조만 준비하고 비활성

## 실행
1. Android Studio에서 저장소를 엽니다.
2. JDK 17을 사용합니다.
3. Gradle Sync 후 Android 기기에서 실행합니다.
4. 첫 음성 입력 때 마이크 권한을 허용합니다.

> 음성 인식은 기기에 설치된 Android 음성 인식 서비스 상태에 따라 네트워크가 필요할 수 있습니다.
