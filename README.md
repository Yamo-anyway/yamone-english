# Yamone English

한국어 사용자를 위한 음성 중심 영어 회화 학습 앱입니다.

## v0.4.0 범위

### 과정
- 영어권 5~7세 과정: 100개 레슨
- 영어권 8~10세 과정: 100개 레슨
- 영어권 11~13세 과정: 100개 레슨
- 영어권 14~16세 과정 1차: 50개 레슨
- 홈에서 과정 선택
- 과정별 학습·듣기·어순·복습 기록 분리
- 화면 번호는 각 과정에서 1번부터 시작

### 5~7세 과정
- 일상 핵심 표현 100개
- 레슨별 6턴 대화
- 영어식 어순 훈련 100개
- 검수 발음 가이드 100개
- 듣기·말하기·어순 통합 자동 복습
- 16문항 과정 종료 테스트

### 8~10세 과정
- 핵심 표현 100개
- 레슨별 6턴 대화 100개
- 영어식 사고·어순 가이드 100개
- 미국식 실제 회화 기준 발음·연결·강세·억양 가이드 100개
- 20문항 과정 종료 테스트

### 11~13세 과정
- 핵심 표현 100개
- 레슨별 6턴 대화 100개
- 영어식 사고·어순 가이드 100개
- 미국식 실제 회화 기준 발음·연결·강세·억양 가이드 100개
- 24문항 과정 종료 테스트

### 14~16세 과정
- 1~50 레슨
- 레슨별 6턴 대화 50개
- 영어식 사고·어순 가이드 50개
- 미국식 실제 회화 기준 발음·연결·강세·억양 가이드 50개
- 의견·뉘앙스
- 선택·설득·타협
- 관계·경계·친구 압박
- 학업·시간 관리·독립성
- 사회·미디어·정보 프레이밍
- 자기표현과 자연스러운 영어 사고
- 기존 듣기 / 말하기 / 어순 / 자동 복습 흐름 적용

### 공통
- Android 기본 TTS(TextToSpeech) 영어 듣기
- 천천히 / 학습 / 자연 / 실제 빠름
- 기본 / 다른 목소리 / A·B 교차 화자
- 영어만 / 영어→해석 / 영어→해석→영어 연속 듣기
- Android SpeechRecognizer 말하기 인식
- 한국어 음성 → 자연스러운 영어 표현 추천
- 로그인/광고/콘텐츠 업데이트/온라인 AI는 구조만 준비하고 비활성

## 실행
1. Android Studio에서 저장소를 엽니다.
2. JDK 17을 사용합니다.
3. Gradle Sync 후 Android 기기에서 실행합니다.
4. 첫 음성 입력 때 마이크 권한을 허용합니다.

> 음성 인식은 기기에 설치된 Android 음성 인식 서비스 상태에 따라 네트워크가 필요할 수 있습니다.
