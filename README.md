# Yamone English

한국어 사용자를 위한 음성 중심 영어 회화 학습 앱의 첫 실행 버전입니다.

## v0.1.9 범위
- 영어권 5~7세 수준의 일상 표현 50개를 앱 내부에 포함
- 듣기 → 의미 이해 → 따라 말하기 → 내 표현 → 짧은 대화 → 완료 흐름
- Android 기본 TTS(TextToSpeech)로 영어 듣기
- 확장 소리 가이드: 영문 리듬 / 천천히 / 실제 소리 / 강약·억양
- 50개 레슨별 6턴 미니 대화
- 집중 듣기 훈련: 문장 숨김 → 반복 듣기 → 가림 힌트 → 뜻 3지선다 → 정답 확인
- 듣기 속도 선택: 천천히 / 학습 / 자연 / 실제 빠름
- 영어 TTS 목소리 선택: 기본 / 다른 목소리 / A·B 교차 화자
- 핵심 문장 1·2·3회 반복 듣기
- 6턴 대화 먼저 듣기 후 대본 확인
- 듣기 전용 연속 재생: 영어만 / 영어→해석 / 영어→해석→영어
- 한 레슨 또는 50개 레슨 전체 연속 듣기
- 한국어→영어식 사고 순서 훈련: 한국어 → 영어식 한국어 순서 → 영어 덩어리 배열 → 직접 말하기
- 50개 핵심문장 전체 어순 훈련 및 로컬 완료 기록
- 한국어 음성 → 자연스러운 영어 표현 추천: 앱 내부 36개 일상 표현 유사도 매칭
- 자연스러운 영어 / 대체 표현 / 리듬 / 한글 소리 가이드 제공
- 추천 영어를 직접 말하고 음성인식 일치도 확인
- 익힌 표현 로컬 완료 기록
- 대화 탭에서 내 표현 / 자유 대화 모드 전환
- Android SpeechRecognizer로 한국어·영어 말하기 인식
- 완료/복습 기록을 기기 로컬에 저장
- 자유 말하기용 로컬 대화 코치
- 로그인/광고/콘텐츠 업데이트/온라인 AI는 구조만 준비하고 비활성

## 실행
1. Android Studio에서 저장소를 엽니다.
2. JDK 17을 사용합니다.
3. Gradle Sync 후 Android 기기에서 실행합니다.
4. 첫 음성 입력 때 마이크 권한을 허용합니다.

> 음성 인식은 기기에 설치된 Android 음성 인식 서비스 상태에 따라 네트워크가 필요할 수 있습니다.
