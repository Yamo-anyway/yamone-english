# Yamone English

한국어 사용자를 위한 음성 중심 영어 회화 학습 앱입니다.

## v0.8.3 범위

### 과정
- 영어권 5~7세 과정: 100개 레슨
- 영어권 8~10세 과정: 100개 레슨
- 영어권 11~13세 과정: 100개 레슨
- 영어권 14~16세 과정: 100개 레슨
- 영어권 17~20세 과정: 100개 레슨
- 총 500개 레슨
- 홈에서 과정 선택
- 과정별 학습·듣기·어순·복습 데이터를 분리
- 화면 번호는 각 과정에서 1번부터 시작

### 과정 종료 테스트
- 5~7세: 16문항
- 8~10세: 20문항
- 11~13세: 24문항
- 14~16세: 28문항
- 17~20세: 28문항
- 듣기·말하기·영어식 어순·상황 대응/판단을 확인
- 틀린 종료 테스트 문항은 통합 자동 복습에 반영
- 과정별 평가 결과 저장소 이름과 저장 키는 기존 버전과 동일하게 유지

### 학습
- 레슨별 자연스러운 실제 회화 핵심 표현
- 모든 500개 레슨에 정확히 6턴 대화
- 영어식 사고·어순 가이드
- 미국식 실제 회화 기준 발음·연결·강세·억양 가이드
- 듣기 → 이해 → 말하기 → 내 표현 → 대화 흐름
- 틀린 듣기·말하기·어순 항목을 통합 자동 복습

### v0.8.3 출시 후보(RC) 코드 점검 2차
- 설정 화면의 버전 표기를 `BuildConfig.VERSION_NAME`에서 가져와 앱 버전과 자동으로 일치하도록 변경
- 복원된 탭 인덱스가 손상되어도 오늘 탭으로 안전하게 보정하도록 내비게이션 상태 방어 추가
- 시스템 뒤로가기에서 설정·과정 테스트·레슨을 먼저 닫고, 일반 보조 탭에서는 오늘 탭으로 복귀하도록 `BackHandler` 적용
- 앱 이름을 문자열 리소스로 이동하고 launcher/adaptive icon 최소 출시 리소스 추가
- Manifest에서 정식 앱 이름, 일반/원형 launcher icon을 사용하도록 변경
- `lintDebug`를 CI에 추가하고 debug APK와 함께 unsigned release APK/AAB도 컴파일하도록 강화
- 릴리스 서명키나 Play Console, 실제 기기 수동 테스트는 자동 완료로 간주하지 않음

### v0.8.2 출시 후보(RC) 코드 점검 1차
- 앱이 직접 네트워크 통신을 사용하지 않는 현재 구조에 맞춰 불필요한 `INTERNET` 권한 제거
- 학습·평가 기록이 OS 클라우드 백업으로 복사되지 않도록 `allowBackup=false`로 백업 정책 명시
- 음성 인식 중복 시작 시 기존 세션을 취소하고 새 콜백을 덮어쓰지 않도록 중복 실행 방어 강화
- 화면 종료 뒤 SpeechRecognizer/TTS 콜백이 다시 상태를 변경하지 않도록 lifecycle 종료 방어 추가
- 연속 듣기 TTS 초기화 실패, 빈 재생목록, 종료 후 재호출, `speak()` 즉시 실패 경로를 안전하게 처리
- TTS 지연 콜백을 중지 시 제거해 화면 전환 뒤 오래된 재생 콜백이 남지 않도록 정리
- 평가 저장값이 음수/최대 문항 수 초과이거나 완료 시각이 비정상인 경우 안전하게 보정·무시
- 자동 복습 오류 횟수가 손상된 값이어도 0~9 범위로 보정해 overflow와 비정상 정렬을 방지
- release 빌드 타입의 minify/ProGuard 정책을 명시적으로 고정
- 실제 기기에서만 가능한 항목은 `RELEASE_CHECKLIST.md`로 분리하고 자동 테스트 완료로 오인하지 않도록 정리

### v0.8.1 출시 전 통합 안정화 2차
- 홈의 과정 진행 상태를 `CourseProgressResolver` 기준으로 통일
- 100/100 전에는 정확한 다음 미완료 레슨과 남은 레슨 수를 표시
- 100/100 완료 뒤 마지막 레슨을 `이어서 학습`으로 다시 노출하지 않고 과정 완료 및 종료 테스트 진입을 우선 표시
- 과정 테스트 카드에서 레슨 진행 중/100개 완료/기존 결과 보유 상태를 구분해 안내
- 선택 과정 외 완료·어순·복습 데이터가 홈 카운트와 복습 화면에 섞이지 않도록 필터 강화
- 저장된 레슨 ID 중 삭제되었거나 잘못된 ID는 읽을 때 안전하게 무시
- 레슨 데이터·섹션이 비정상적으로 비어 있어도 홈에서 크래시하지 않는 빈 상태 처리 추가
- 모든 TTS 호출을 공통 경로로 통합하고 TTS 준비 실패/영어 음성 미지원 시 Snackbar 안내 추가
- 기존 SharedPreferences 이름·키·평가 저장소 이름은 그대로 유지

### 품질 점검
- 5개 과정 × 100개 레슨의 고정 ID와 과정별 1~100 번호 검사
- 모든 레슨의 6턴 대화 존재 여부 및 빈 문장 검사
- 영어식 어순 가이드와 발음·연결·강세·억양 가이드 누락 검사

- 14~16세·17~20세 종료 테스트 문항 수·분야 균형·전 범위 샘플링 검사
- 저장소/저장 키 이름이 과거 버전과 동일한지 회귀 검사
- 99/100과 100/100 홈 흐름을 5개 과정 모두 회귀 검사
- 손상된 평가 점수와 복습 오류 횟수 보정 로직 회귀 검사
- 비정상 탭 복원값과 보조 탭 뒤로가기 목표를 순수 로직으로 회귀 검사

- 천천히 / 학습 / 자연 / 실제 빠름
- 영어만 / 영어→해석 / 영어→해석→영어 연속 듣기

## 실행
1. Android Studio에서 저장소를 엽니다.
2. JDK 17을 사용합니다.
3. Gradle Sync 후 Android 기기에서 실행합니다.
4. 첫 음성 입력 때 마이크 권한을 허용합니다.

CI에서는 `:app:testDebugUnitTest`, `:app:lintDebug`, `:app:assembleDebug`, `:app:assembleRelease`, `:app:bundleRelease`를 실행해 회귀 테스트·lint·debug APK·unsigned release APK/AAB 컴파일을 확인합니다.

> 음성 인식 서비스 자체는 기기/서비스 상태에 따라 네트워크를 사용할 수 있지만, Yamone English 앱은 현재 직접 네트워크 API를 호출하지 않습니다.

## 출시 전 남은 확인
실제 기기와 스토어 계정이 필요한 항목은 [`RELEASE_CHECKLIST.md`](RELEASE_CHECKLIST.md)에 별도로 관리합니다. 자동 CI 성공만으로 실제 기기 테스트, 릴리스 서명, Play Console 설정이 완료된 것으로 간주하지 않습니다.
