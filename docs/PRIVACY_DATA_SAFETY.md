# Yamone English — Privacy / Data Safety Review Draft

> 상태: **검토 초안**. 이 문서는 공개 개인정보처리방침이나 Play Console Data safety 제출 완료본이 아닙니다. 실제 출시 빌드, 기기에서 선택되는 SpeechRecognizer/TTS 제공자, 최종 사업 운영 방식과 Google Play의 당시 정의를 기준으로 최종 확인해야 합니다.

## 1. 현재 코드 기준 데이터 흐름 요약

현재 Yamone English v0.8.4는 로그인, 광고 SDK, 분석 SDK, 자체 서버 API, 온라인 AI API를 활성화하지 않습니다. 앱 코드가 직접 운영 서버로 학습 데이터를 전송하는 네트워크 경로도 현재 없습니다.

AndroidManifest의 런타임 민감 권한은 다음과 같습니다.

- `android.permission.RECORD_AUDIO`

앱의 직접 `INTERNET` 권한은 현재 선언하지 않습니다.

## 2. 기기 내부에 저장되는 정보

현재 앱은 Android `SharedPreferences`를 이용해 다음과 같은 학습/설정 데이터를 기기 내부에 저장합니다.

- 선택한 과정 (`selected_course`)
- 완료한 레슨 ID (`completed`)
- 복습 대상 레슨 ID (`review`)
- 영어식 어순 완료 레슨 (`thinking_completed`)
- 표현/대화 완료 상태 (`expression_completed`)
- 듣기 속도
- 한국어 도움말 표시 여부
- 발음·리듬 가이드 표시 여부
- 5개 과정의 종료 테스트 결과/점수 및 관련 로컬 평가 정보
- 통합 복습의 로컬 오류/성공 상태

이 저장 키와 레슨 내부 ID는 기존 버전 호환을 위해 유지합니다.

`android:allowBackup="false"`를 사용하므로 앱 데이터의 Android OS 클라우드 백업을 허용하지 않는 것이 현재 제품 정책입니다.

## 3. 마이크 / 음성 인식

### RECORD_AUDIO 사용 목적

마이크 권한은 사용자가 다음 기능을 명시적으로 실행할 때 영어 또는 한국어 발화를 음성 인식하기 위해 사용합니다.

- 레슨 따라 말하기
- 내 문장 말하기
- 영어 대화 응답
- 과정 테스트의 말하기 항목
- 한국어 음성을 통한 자연스러운 영어 표현 연습

앱은 사용자가 말하기 버튼을 눌렀을 때 Android `SpeechRecognizer`를 시작하며, 인식 결과 텍스트를 현재 화면의 학습 피드백에 사용합니다.

### 앱 자체 저장 여부

현재 코드에서는 원본 마이크 오디오 파일을 앱의 영구 저장소에 저장하지 않습니다. 인식된 발화 텍스트도 일반 학습 화면에서는 화면 상태로 사용되며 별도의 영구 발화 기록 데이터베이스로 저장하지 않습니다.

### 외부 서비스 처리 가능성

중요: Android `SpeechRecognizer`의 실제 구현은 기기 제조사, Android 시스템, 설치된 음성 인식 서비스 제공자에 따라 다릅니다. 해당 서비스가 음성을 기기에서 처리할 수도 있고, 네트워크를 통해 서비스 제공자 측에서 처리할 수도 있습니다.

따라서 다음 두 문장을 구분해야 합니다.

1. **Yamone English 앱 코드 자체가 자체 서버/API로 음성을 전송하지 않는다.**
2. **사용자가 선택/설치한 Android 음성 인식 서비스가 음성을 외부 처리하지 않는다고 보장하는 것은 아니다.**

Play Console Data safety 응답과 공개 개인정보처리방침에서는 이 차이를 명확하게 반영해야 합니다.

## 4. TTS(Text-to-Speech)

앱은 Android `TextToSpeech`를 사용해 영어 문장과 일부 학습 문구를 읽어줍니다.

- 앱 코드가 직접 TTS 서버를 호출하지 않습니다.
- 실제 합성이 온디바이스인지 네트워크 기반인지 여부는 설치된 TTS 엔진/서비스에 따라 달라질 수 있습니다.
- 앱이 TTS에 전달하는 텍스트는 레슨 콘텐츠와 학습 화면에서 재생할 문구입니다.

최종 개인정보처리방침에는 “기기/서비스 제공자의 음성 인식 및 음성 합성 기능을 사용하며 해당 제공자의 정책이 적용될 수 있음”을 설명하는 것이 안전합니다.

## 5. 현재 활성화되지 않은 기능

현재 코드/제품 범위에서는 다음 기능이 비활성 상태입니다.

- 회원가입/로그인
- 클라우드 기기 동기화
- 자체 분석/통계 서버 전송
- 광고 SDK
- 온라인 AI 회화
- 서버 기반 콘텐츠 업데이트

향후 하나라도 활성화하면 이 문서와 Play Data safety 응답을 반드시 다시 검토해야 합니다.

## 6. 현재 코드 기준 '수집/공유' 판단 초안

Google Play Data safety의 `수집(collect)`/`공유(share)` 여부는 Google Play의 당시 정의와 실제 출시 빌드의 동작을 기준으로 답해야 합니다. 다음은 개발 검토용 초안입니다.

### 앱이 직접 관리하는 학습 데이터

- 학습 진행/설정/평가 데이터: 현재 기기 내부 저장
- 자체 서버 전송: 현재 없음
- 제3자 분석 SDK 전송: 현재 없음
- 광고 SDK 공유: 현재 없음

따라서 **앱 자체 코드 관점에서는 로컬 학습 데이터를 외부로 직접 수집/공유하지 않는 구조**입니다.

### 음성 데이터

음성 인식은 Android 시스템/서비스 제공자를 통하므로 단순히 “음성을 전혀 외부에 보내지 않는다”라고 단정해서는 안 됩니다. Play Console 최종 Data safety 작성 시 다음을 실제 기기/배포 환경에서 확인해야 합니다.

- 기본 SpeechRecognizer 제공자가 누구인지
- 해당 제공자의 온디바이스/클라우드 처리 방식
- 사용자가 다른 음성 서비스 제공자를 선택할 수 있는지
- Play Data safety에서 시스템 서비스 처리에 대해 어떤 공개가 요구되는지

## 7. 보안 / 보존 정책 초안

현재 구조:

- 학습 데이터는 앱의 로컬 저장소에 보존
- 앱 내 계정이 없으므로 서버 계정 삭제 기능 없음
- 사용자는 Android 앱 데이터 삭제 또는 앱 제거로 로컬 학습 기록을 제거할 수 있음
- `allowBackup=false`로 OS 백업 복원은 현재 차단
- 원본 음성 파일을 앱이 지속적으로 저장하지 않음
- keystore/서명키는 저장소에 포함하지 않아야 함

향후 서버/계정 기능이 추가되면 보존기간, 삭제 요청, 전송 암호화, 서버 위치, 국외 이전 여부 등을 별도로 정의해야 합니다.

## 8. 공개 개인정보처리방침에 포함할 내용 초안

실제 공개 정책에는 최소한 다음 내용을 제품 운영 주체 정보와 함께 작성해야 합니다.

1. 앱이 제공하는 서비스 개요
2. 기기 내부에 저장되는 학습 진행/설정 정보
3. 마이크 권한 사용 목적
4. 원본 음성을 앱 자체 저장소에 영구 저장하지 않는 현재 정책
5. Android SpeechRecognizer/TTS가 기기 또는 외부 서비스 제공자에 의해 처리될 수 있다는 안내
6. 앱 자체 서버/분석/광고 네트워크가 현재 비활성이라는 사실
7. 앱 삭제/앱 데이터 삭제를 통한 로컬 기록 삭제 방법
8. 문의처 및 개인정보 관련 연락 수단
9. 정책 시행일/변경 이력
10. 향후 온라인 기능이 추가될 경우 정책이 변경될 수 있다는 안내

이 문서를 그대로 공개 개인정보처리방침으로 사용하지 말고, 실제 개발자/사업자 정보와 연락처를 넣은 별도 공개 문서를 만들어 URL로 제공해야 합니다.

## 9. Play Console Data safety 최종 작성 체크리스트

- [ ] 실제 출시 대상 AAB의 Manifest 권한을 확인한다.
- [ ] 앱 코드에 새 네트워크 라이브러리/SDK가 추가되지 않았는지 다시 검색한다.
- [ ] 광고/분석/로그인/Crash SDK가 정말 비활성인지 확인한다.
- [ ] Android SpeechRecognizer의 데이터 처리 특성을 최종 배포 환경 기준으로 확인한다.
- [ ] TTS 엔진의 데이터 처리 특성을 확인한다.
- [ ] 사용자에게 RECORD_AUDIO 권한이 필요한 이유를 앱 내/스토어 정책과 일치시킨다.
- [ ] Google Play의 현재 `Collected`, `Shared`, `Ephemeral processing` 정의를 제출 시점에 다시 확인한다.
- [ ] 공개 개인정보처리방침 URL의 설명과 Play Data safety 응답이 서로 모순되지 않는지 확인한다.
- [ ] 앱이 아동을 실제 대상 사용자에 포함할 경우 아동/가족 정책에 필요한 추가 공개를 검토한다.

## 10. 코드와 정책 변경 시 재검토 트리거

다음 변경이 생기면 Data safety와 개인정보처리방침을 출시 전에 다시 검토합니다.

- 로그인/회원 계정 추가
- 서버 동기화 추가
- 광고 SDK 추가
- 분석/Crash reporting SDK 추가
- 온라인 AI API 추가
- 자체 음성 업로드/저장 기능 추가
- 결제/구독 추가
- 위치/연락처/사진 등 새 권한 추가
- 클라우드 콘텐츠 업데이트 활성화

## 11. 현재 결론

v0.8.4 기준으로 Yamone English는 **로컬 학습 기록 + Android 플랫폼 음성 서비스** 중심 구조입니다. 자체 네트워크 API가 없다는 점은 소스 기준으로 확인되지만, SpeechRecognizer/TTS 서비스 제공자의 처리까지 포함해 “어떠한 데이터도 외부 처리되지 않는다”고 단정해서는 안 됩니다.

따라서 Play Console Data safety와 공개 개인정보처리방침은 **실제 출시 환경 확인 후 최종 확정**합니다.
